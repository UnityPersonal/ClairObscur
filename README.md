# ClairObscur

# 1. Project Overview [프로젝트 개요]

- 클레를 옵스퀴를 33 원정대 전투 시스템 모작 프로젝트
- **Unity 3D** 로 제작한 게임입니다.  
- **개발 기간:** 2025.6 ~2025.6 (3주)

---

# 2. Key Features [주요 기능]

## 2.1 Battle Action
- **BattleAction:** 다양한 스킬 연출, 전투 시스템을 **Timeline** 기반으로 통합 관리
- **Signal Asset** 기반으로 전투와 연출 상호작용

## 2.2 Actor
- Timeline 에서 동적으로 변한 연출 설정으로 Actor을 통해 동적으로 세팅할 수 있도록 지원

## 2.3 Skill
- 태그 기반의 스탯을 조회에 스킬 효과 부여

## 2.4 Manager
- **BattleEventManager:** 전투 상호작용에 필요한 이벤트 관리
